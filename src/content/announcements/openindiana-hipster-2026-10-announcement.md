The OpenIndiana Hipster 2026.10 snapshot is available. Visit the [Downloads](/downloads) page for the Live, Text and Minimal installation images, dated 30 October 2026. Existing installations can continue to [update through IPS](https://docs.openindiana.org/handbook/getting-started/#image-package-system-ips).

## Notable Changes

- **UEFI framebuffer support on the Live image.** The `illumosfb` Xorg driver is now enabled, installed in the X server's module path and included on the Live image, with automatic configuration on illumos framebuffer consoles.
- **Updated browsers and mail.** Firefox and Thunderbird reach version 159.0.
- **Development tools.** Python 3.15.2 and Perl 5.44.0 are added, alongside Rust 1.99.0, Clang 23.1.4 and GCC 15.3.0. Interpreter additions are listed separately from the many module updates below.
- **Virtualization updates.** QEMU reaches 11.1.2 and VirtualBox 7.2.22; the QEMU guest agent is split into its own package.
- **New applications.** TeX Live 2026 and the Foliate 3.2.1 ebook reader join the collection, along with the `zoxide` shell navigation tool.

Other changes include OpenSSH 10.6p1, OpenSSL 3.5.9, MariaDB 12.3.3 and further SPARC build support for applications including OpenJDK 11/17, ripgrep and Claws Mail.

### Snapshot notes

- **Updated cloud and Vagrant images.** Supplemental images built on 7 November 2026 are available from [Downloads](/downloads), including a 50 GiB libvirt Vagrant box. These use pinned November 7 Hipster packages; the installation snapshot and changelog below remain dated October 30.
